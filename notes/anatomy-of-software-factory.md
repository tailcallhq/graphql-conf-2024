# Anatomy of a Software Factory

## What is a Software Factory?

- Coined in 1968
- "Organizations that build standardized environments to mass-produce code"

## Deck Notes

- No full stops anywhere
- High level points only: 1 to 2 words
- Tell the story with SVG visuals and animations, not text

## Agenda

1. Why Factories?
   - Individual Ceiling
   - Org Velocity
   - Repeatability
2. Individual or Org?
   - Individual: Faster Developer
   - Org: More Output
   - Bottleneck: Coordination
3. What Goes In?
   - Triggers
   - Specs
   - Issues
   - Context
4. How Is Work Routed?
   - Triage
   - Routing
   - Handoffs
5. How Is It Built?
   - Orchestration
   - Parallel Agents
   - Specialization
6. How Does It Scale?
   - 10 → 1000
   - Cloud
   - Always On
   - Shared Context
   - Working Copies
7. How Is Quality Kept?
   - Reviews
   - Tests
   - Guardrails
8. What Comes Out?
   - Pull Requests
   - Shipping
   - Metrics
9. Which Roles Automate?
   - QA: 100%

   - Platform: 40%
